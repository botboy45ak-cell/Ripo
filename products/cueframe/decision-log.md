# Product decision log

## 2026-11-26 — first cross-device prototype

- Selected a reusable visual-cue/overlay kit rather than a desktop preset, because the user edits on CapCut Mobile and asked for both phone and PC users.
- Narrowed the use cases to tutorials/explainers, product demos, comparisons, and short personal stories; three coherent visual styles are included to support different aesthetics without embedding English labels.
- Use standard transparent PNG layers as the main delivery format. This is more widely importable than app-specific project files; SVG source is optional.
- Created a draft product system, asset generator, 96 transparent PNGs, 96 editable SVG sources, device guides, preview gallery, offline storyboard planner, and prototype bundle. The assets are original vector geometry, not the previously rejected tutor starter ZIP.
- Kept all work outside `public/`; no tutor offer, live form, approved QR, or site deployment has been changed.
- Release gate remains open: actual phone/desktop smoke tests, brand-name review, platform/guardian/payment/KYC research, and tax review are not complete.
