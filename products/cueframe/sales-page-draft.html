Plan the beats before you edit.

The bundled offline planner creates a simple time-coded storyboard for a tutorial, product demo, comparison, or personal story. Edit the shot and narration notes, then download the plan as text or print it. It runs locally in the browser and sends no topic data to a server.

Quick workflow

From download to edit in three steps.

STEP 01

Match the frame

Use 9:16 for vertical projects or 16:9 for wide projects; choose one of the three styles.

STEP 02

Layer the PNG

On mobile, add it as an image overlay. On desktop, place it on a track above the footage.

STEP 03

Add your words

Use a separate text layer, check it on the small screen, then export a short test.

Questions before release

What this prototype can—and can't—claim.

Will it work on phones and computers?

It is built from transparent PNG image layers, intended for editors that support image overlays. A phone and desktop smoke test is still required; no universal compatibility claim is made yet.

Is this a CapCut preset or template?

No. It is not a native project, preset, or plugin. It is a folder of image layers, with separate general phone and desktop instructions.

Are the graphics animated?

No. This v0.1 overlay kit contains static PNG/SVG artwork. Cueframe Motion Studio is a separate experimental editor; it does not turn this kit into a native animation template or guarantee import support.

Can I buy it now?

No. This is a draft product page. The product, price, seller account, checkout, and legal/tax route are not approved or set up.
