# General workflow: any editor with image layers

Cueframe uses ordinary transparent PNG files rather than an app-specific template. In any editor that can import transparent PNG images and layer them over footage:

1. Pick `vertical` (1080×1920) or `wide` (1920×1080) to match the project.
2. Import the PNG as an image/overlay layer above your footage.
3. Set its start and end time, and position it without stretching.
4. Add editable wording in your editor, if needed.
5. Preview and export a short test before using it in a full project.

The PNG artwork is static. It is not an animated transition, a native CapCut template, a LUT, a font, a video preset, or a replacement for editing skills. Optional SVG files are intended for people who want to modify vector artwork; use the PNGs if your phone editor does not accept SVG.
