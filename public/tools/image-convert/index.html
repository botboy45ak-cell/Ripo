Helpful answers

Questions about Convert image format

Which formats can I save?

Choose JPG, PNG, or WebP as the new image format.

Can a JPG keep transparency?

No. JPG is opaque; choose a background color when converting an image with transparent areas to JPG.

Does changing the file extension convert an image?

No. This tool decodes the image and writes a new file in the selected format; renaming alone would not convert it.
